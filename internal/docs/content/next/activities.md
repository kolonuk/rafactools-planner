# Activities

Click an **Activity** box in a programme's grid and the browser suggests activities as you type. You can always type anything else: the list only saves typing.

## The built-in list

Every squadron is offered the same built-in activities: First Class - Flying Operation, First Class - Map Reading, First Class - Initial Expedition Training, First Class - Radios, Leading - Pilot Navigation, Leading - Principles of Flight, First Class - History of the RAF, First Class - History of ATC, Annual Briefings, Climatic Injuries, DofE Prep, Laser Quest, Bowling, Section Visit and Guest Speaker - RAF Police. It cannot be changed.

## Your squadron's own

Owners and editors open **Activities** in a programme's menu bar. Add an activity (up to 120 characters), click one to rename it, or choose **Remove**. Only your squadron is offered them, and a squadron can have up to 300.

An activity whose name matches a built-in one (ignoring capitals and extra spaces) is refused, and if one gets in some other way, such as a later release adding it to the built-in list, it is deleted for every squadron when the site starts.

Removing an activity from the list does not change any programme that already uses it.
